# NEXT - Plataforma de Educação Financeira (Frontend Sandbox)

O NEXT é uma aplicação web moderna focada em educação financeira e simulação de investimentos para iniciantes. É um ambiente simulado (sandbox) com o objetivo de demonstrar o impacto dos juros compostos em Fundos Imobiliários (FIIs) sem riscos financeiros reais.

> ⚠️ **Status do Projeto:** Em Desenvolvimento (Protótipo Inteiramente Frontend com Dados Mockados).

---

## 🚀 Como Iniciar o Frontend Localmente

### 1. Pré-requisitos
Certifique-se de possuir o [Node.js](https://nodejs.org) (versão 18 ou superior) instalado em sua máquina.

### 2. Instalar as Dependências
Abra o terminal na pasta raiz deste projeto e execute o comando:
```bash
npm install
```

### 3. Iniciar o Servidor de Desenvolvimento
Para testar a interface de forma interativa e com suporte a atualizações instantâneas, inicie o Vite executando:
```bash
npm run dev
```

Após iniciar, o terminal indicará a porta local correspondente (geralmente `http://localhost:3000`).

## 🎨 Características do Sistema
- **Identidade Unificada de Fintech:** Estilo de alta legibilidade inspirado nas principais plataformas SaaS mundiais.
- **Gráficos Avançados com Recharts:** Amortização e compounding projetado em formato de área, além de diversificação recomendada em pizza.
- **Simulador Científico:** Motor matemático que calcula rendimentos fictícios considerando frações e número mágico de cotas.
- **Estrutura Pronta:** Pronta para conexões futuras com Firebase Auth e Firestore.
